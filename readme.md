# Experimentos de RUL (Remaining Useful Life)

Experimentos de predicción de vida útil remanente (RUL) en rodamientos. Incluye scripts, análisis y gráficos de resultados descartados.

## Aviso

Este repositorio es un registro personal de experimentos. Se publica solo para consulta: el código puede estar desordenado, no tiene mantenimiento ni soporte, y se entrega tal cual, sin garantías de ningún tipo. Si algo te sirve, puedes usarlo bajo tu propia responsabilidad.

## Contenido

Cada carpeta corresponde a un experimento independiente y contiene sus scripts, resultados y gráficos.

## Datos

Los datos originales no están incluidos. Debes descargarlos desde su fuente oficial.

Si contiene los archivos corregidos del Bearing1_1, son acc02121 y acc02122, además se siguiere corregir Bearing1_4 que tiene los datos separados por ";" y deben ser por ",", existe un script que lo corrigue en carpeta rul_bearing_phm/scripts, buscalo.

Las rutas en los scripts aparecen como `escribe aqui tu ruta`; reemplázalas por las de tu entorno.
